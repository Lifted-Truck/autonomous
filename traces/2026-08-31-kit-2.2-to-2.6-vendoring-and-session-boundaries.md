# Trace — kit 2.2.0 → 2.6.0: from copied gates to computed currency

**Arc:** 2026-08-17 → 2026-08-31 · 69 commits · Decisions 47–66 · LIBRARY L0001–L0015
**Closed by:** the first `/breakdown` this repo has ever run.

## What changed, in one line

The kit stopped **copying** mechanism into repos and stopped **asking** them
what version they were.

## The through-line

Every substantive defect in this arc was one shape, found five times, each
time by a check written by someone who had already learned it from the last
one: **a check asked a question adjacent to the one that mattered, and passed
while the thing itself was broken.**

1. `contains:leak_gate` asked whether the gate's NAME appeared → 2.2.0 made it
   FIRE (spectral-morph).
2. Gate code was copied, so ten variants existed, nine missing the Windows
   pattern, while every repo declared a `kit_version` promising it → 2.4.0
   vendored it, checksum-pinned (Decision 65).
3. `.gitattributes` was checked for PRESENCE while untracked → 2.5.0 checks
   TRACKED (Tonality).
4. `kit_sync` reported `current` for canonical bytes that were untracked and
   unsourced — healthy on exactly one disk → 2.5.1 (terrane; the intersection,
   LIBRARY L0014).
5. Currency itself was a DECLARATION that went stale on its own: 24 repos
   retrofitted the same day read BEHIND again, all 24 meeting every
   requirement → 2.6.0 computes it from the tree.

## What the fleet did, not just this repo

Residents found the defects this repo shipped, and the good ones arrived as
design arguments rather than bug reports: mind-lathe (probe clobbered
`.harness/`, then the plant-collision race), attest (my audit probe reddened
their verify), Place (an orphaned plant after a timeout, and the CI action
majors two versions stale), vertex + tribos independently (a MANIFEST version
line two readers misread), Tonality (untracked `.gitattributes`; and the
`ball: none` blind spot), distillery (two parser bugs my own validator shared).
HYPERSAW's round-3 argument — *take the duty off the party that cannot be
gated* — is the operative sentence of an amendment now at the S5 gate.
