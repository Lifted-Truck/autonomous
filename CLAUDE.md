# autonomous — resident charter (lean root: pointers + gotchas)

The global doctrine (imported via `~/.claude/CLAUDE.md`) applies on top of
this file and is not restated. This is the standards + kit + governor repo —
the fleet's S5. Orient in this order: `README.md` → `ROADMAP.md` (single
source of truth for direction; current phase marked) → `DECISIONS.md` (tail
first — the file is NOT in numeric order) → `governor/STATUS.md` (gitignored,
regenerated by the session hook).

## Territory and writes

- Residents commit and push to `main` directly. Visibility flips,
  credentials, cross-repo pushes, and merges of audit PRs are the human's.
- **This repo is PUBLIC.** Nothing here names private repos, machines, or
  people: `governor/STATUS.md` is gitignored for that reason. `./verify`
  runs the leak_gate on tracked AND untracked files.
- `integrations/<repo>/` is the mailbox. Visitors write briefs there and
  leave them uncommitted; committing them is a resident act. `ball_scan`
  reports what is owed.

## Gotchas (each cost an incident — see LIBRARY.md)

- `git grep -E` is POSIX ERE: **no `\s`, `\d`, `\b`** — they match nothing
  and the gate ships green. Plant a known-bad and watch it fire before
  trusting any new detector (L0002).
- `DECISIONS.md` is append-only and out of numeric order; the next number is
  `max + 1`, not `last + 1`.
- `DOCTRINE.md` has a 9000-char budget enforced by `./verify`. Over budget
  means merge or delete a tenet, never bypass.
- Two detectors, one policy: the bash `leak_gate` in `verify` and
  `governor/leak_scan.py` must carry the same patterns and placeholder
  class. Change both or the monitor false-flags repos the gate passes.
- Absence is never "current": no `kit_version` = `pre-2.0.0`, no `dormant`
  = not dormant, no `respond-by` = not overdue. Silence reads as the
  conservative state, always.
- Read the remote, not a recollection: PR merge state comes from `gh`, never
  from chat. Three "merged" reports in two days had three different causes.

## Oracle

`./verify fast` (Layer-0, CI-blocking): leak_gate, sweep + governor + kit-gate
unit tests, registry/JSON parse, doctrine budget. `./verify full` adds the
registry resolve. Both must be green before any commit here.
